# Churn-Detection-Pipeline
Projek ramalan kadar berhenti langganan pelanggan (Customer Churn) menggunakan dataset berskala besar melalui algoritma Random Forest Classifier, lengkap dengan proses pengendalian nilai kosong (missing values), pengekodan binari dan ordinal (Binary &amp; Ordinal Encoding), serta penilaian model menggunakan laporan klasifikasi dengan pipeline
